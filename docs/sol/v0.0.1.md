# SOL Editor v0.0.1

Status: development

## Objective

Create a reproducible collaboration layer around Ultimate Doom Builder and DoomTools before modifying editor internals.

## Included

- Pinned DoomTools source revision.
- Linux bootstrap script that clones and builds DoomTools locally.
- Shared SOL build and engine-launch commands.
- SOL workspace directories and project metadata.
- E1M1 graybox authoring checklist.
- Shared branding asset contract.
- Automated metadata and shell validation.

## Explicitly deferred

- Rebranding the Ultimate Doom Builder UI.
- Embedding DoomTools inside the editor process.
- Final application icons and installers.
- Transition-anchor editor plugins.
- Final E1M1 map geometry.
- Commercial IWAD resources.

## Acceptance checks

1. `sol/version.json` parses as JSON.
2. All `tools/sol-*.sh` scripts pass `bash -n`.
3. `tools/sol-bootstrap-doomtools.sh` checks out the pinned DoomTools commit.
4. `tools/sol-build.sh` creates `build/sol/sol-e1m1-v0.0.1-dev.pk3`.
5. `tools/sol-test.sh` uses the same `SOL_ENGINE` and `DOOM_IWAD` environment contract as `sol-engine`.
6. No IWAD data or locally generated tool files are tracked.

## Next release

`v0.1.0` begins with the first playable E1M1 graybox and documented editor configuration for the SOL engine.
