# SOL Editor v0.1.0

Status: development

## Objective

Deliver a reproducible, editable, playable E1M1 graybox, preserve classic Doom episode progression, and provide a deterministic local workspace setup.

## Included

- Fourteen connected areas from the arrival lock through Exit Control.
- Generator source, generated PWAD, layout overview, and structural statistics.
- 176 staged graybox monster placements and a normal Doom exit interaction.
- Deterministic generation, validation, packaging, and test-launch commands.
- PWAD bounds, lump-order, UDMF reference, sector-connectivity, exit, player-start, weapon-progression, thing-bound, and actual monster-type validation.
- Local workspace initializer for sibling `sol-engine`, `sol-editor`, and `vend` directories.
- IWAD header validation, copy/link modes, checksum manifest, generated `.sol-env`, and strict local `sol-engine` selection.
- Shared SOL application icon integrated into the editor build.
- Mono-compatible bitmap-backed ICO generation for Linux `.resx` compilation.
- Updated Linux, Windows, Flatpak, and SOL GitHub Actions workflows.
- Explicit NuGet restore before the mixed .NET Framework and .NET 8 Windows solution build.

## Acceptance checks

1. The generator reproduces the committed map budgets and layout.
2. The PWAD contains `E1M1`, `TEXTMAP`, and `ENDMAP` in that order with a valid terminal directory and in-bounds lumps.
3. Structural counts, sector connectivity, thing bounds, and the actual 176-monster population match the release contract.
4. The map contains one player-one start, the graybox weapon progression, and one player-use normal exit.
5. Completing E1M1 reaches Doom's normal statistics screen and Episode 1 world map.
6. The workspace initializer selects a built sibling `sol-engine`, validates user-owned IWADs, packages the runtime, and produces a reusable `.sol-env`.
7. The packaged PK3 contains `maps/E1M1.wad` and `SOLINFO`.
8. Linux, Windows, Flatpak, and SOL validation workflows complete successfully.
9. A local test launch reaches E1M1 with no MAPINFO or ZScript errors.

## Deferred

- Production geometry, final lighting, original texture set, soundscape, scripted story events, custom intermission art, and later episode-map iteration.
