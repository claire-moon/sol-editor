# SOL Editor v0.1.0

Status: development

## Objective

Deliver a reproducible, editable, playable E1M1 graybox and restore trustworthy inherited CI.

## Included

- Fourteen connected areas from the arrival lock through the E1M2 transition seam.
- Generator source, generated PWAD, layout overview, and structural statistics.
- 176 staged graybox monster placements and explicit exit interaction.
- Deterministic generation, validation, packaging, and test-launch commands.
- PWAD bounds, lump-order, UDMF reference, sector-connectivity, exit, player-start, weapon-progression, thing-bound, and actual monster-type validation.
- Shared SOL application icon integrated into the editor build.
- Mono-compatible bitmap-backed ICO generation for Linux `.resx` compilation.
- Updated Linux, Windows, Flatpak, and SOL GitHub Actions workflows.
- Explicit NuGet restore before the mixed .NET Framework and .NET 8 Windows solution build.

## Acceptance checks

1. The generator reproduces the committed map budgets and layout.
2. The PWAD contains `E1M1`, `TEXTMAP`, and `ENDMAP` in that order with a valid terminal directory and in-bounds lumps.
3. Structural counts, sector connectivity, thing bounds, and the actual 176-monster population match the release contract.
4. The map contains one player-one start, the graybox weapon progression, and one player-use normal exit.
5. The packaged PK3 contains `maps/E1M1.wad` and `SOLINFO`.
6. Linux, Windows, Flatpak, and SOL validation workflows complete successfully.
7. A local test launch reaches E1M1 with no MAPINFO or ZScript errors.

## Deferred

- Production geometry, final lighting, original texture set, soundscape, scripted story events, and seamless E1M1-to-E1M2 transfer.
