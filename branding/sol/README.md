# SOL Branding Assets

The shared SOL engine/editor icon was approved by the project owner on 2026-08-06.

## Source contract

The unmodified master image will be stored at:

`branding/sol/sol-icon-master.png`

The same artwork is used for both `sol-engine` and `sol-editor`. Do not redraw, recolor, add labels, or create separate engine/editor symbols without a documented design decision.

## Derived files

Build tooling may generate these files from the master image:

- `sol-icon-16.png`
- `sol-icon-32.png`
- `sol-icon-48.png`
- `sol-icon-64.png`
- `sol-icon-128.png`
- `sol-icon-256.png`
- `sol-icon-512.png`
- `sol-icon.ico`

Generated variants should preserve transparency, aspect ratio, and the original color treatment.
